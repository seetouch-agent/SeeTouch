## 代码中的数据暴露面

以下来自源码检查，属于风险或缺口，不是已经发生攻击的证据。本轮以文档同步和审计为范围，未修改这些运行行为。

1. **Web 调试器缺少访问控制**：`seetouch/debugger/app.py` 监听 `0.0.0.0`、CORS 为 `*`，未实现认证；连接者可访问截图/日志并触发设备动作，Guard 自动同意。应加认证、限制监听/来源并实现确认交互。
2. **云端与本地任务数据**：模型收到截图、指令、摘要；Session 和调试器保留动作文本、prompt 和截图。没有自动脱敏，日志/trace/回放不宜直接公开。
3. **Android 凭据与备份**：`settings/AppSettings.kt` 使用普通 SharedPreferences；manifest 开启 backup，XML 未显式排除凭据和运行数据。建议设计凭据存储和备份排除策略。
4. **Android exported 入口**：manifest 中诊断和 helper Activity 公开导出，未附加限制调用者的自定义权限。它们不应被视作“只能通过 ADB 调用”；应用索引/logcat 可能暴露设备安装信息。
5. **诊断输出**：`scripts/doctor.py` 打印 key 前 6 位和设备信息；`diag.TaskRunActivity` 的命令行 key 用法会进入命令历史，日常使用应避免这种传参方式。
