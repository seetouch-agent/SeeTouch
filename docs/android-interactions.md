# Android 连接测试、任务控制与人机交互

对应 Android 1.4（versionCode 5），覆盖 FR-ACC-05、FR-INT-01–05、FR-RES-01–05 及 IR-03–05 的本体交互。实现位于 SeeTouch 本体，不依赖网关；实际扣费额度由服务商账单确定。

| 需求 | 使用方式与行为 |
|---|---|
| ACC-05 连接测试 | 设置页点击“测试连接”，使用当前填写、尚未保存的配置，向所选协议发送内置示例图及固定问题。成功显示耗时；失败区分网络、鉴权、额度、模型/接口不存在、无法解析，另外区分限流和服务异常。测试不读取手机屏幕，不执行模型动作。修改配置后旧测试结果失效。 |
| INT-02 暂停、继续、终止 | App、进度浮窗和任务通知提供控制按钮。暂停立即关闭新动作入口，已派发的手势可以结束；已发出的请求可等待返回，结果保留但不执行。继续后重新截图和推理。终止后禁止恢复、禁止新动作；正在等待的请求可能到超时才释放后台线程，期间不能启动另一任务。 |
| INT-01 / IR-03 浮窗 | 进度窗可拖动，显示当前步骤、动作与阶段，展开查看最近 5 步。空闲悬浮球可拖动、贴边吸附、关闭；展开后支持文字、系统语音和最近 3 条指令，从当前应用开始，不先回桌面。截图和自动操作前隐藏悬浮组件。 |
| INT-03 ASK_USER | 模型可输出问题和选项。App、浮窗支持选项、文字和系统语音识别，通知提供文字/语音回答入口；识别文字只填草稿，需确认提交。通知不直接展示问题、选项或回答。5 分钟未回答进入暂停，保留问题；回答写入当前步骤和后续任务上下文。用户主动暂停后提交答案仍保持暂停，需再点继续。 |
| INT-04 TAKE_OVER | 无障碍节点检测密码、验证码、登录表单、生物识别、滑块等页面，模型也可主动请求接管；用户可随时点“我来操作”。接管期间不发起新的截图、模型请求或自动操作。用户完成后点击继续，重新观察页面。只记录接管边界和原因，不记录人工操作过程。 |
| INT-05 / IR-04 敏感确认 | App 与浮窗显示操作前截图、目标红圈、动作说明、可能后果、倒计时及“允许本次 / 拒绝”；拒绝为默认焦点。默认 60 秒，设置可调 10–600 秒；超时拒绝，过期或重复点击不能放行。通知也提供确认按钮。动作、截图、选择和时间写入本地审计。 |
| RES-01/02 结果 | 结果卡片显示最终状态、12 类原因及建议、步数、耗时和模型输入/输出用量；不估算或伪造扣费额度。支持结构化 `ANSWER`，或 `COMPLETE` 携带 `answer` / `source_step`；来源必须对应本次实际保存的截图。模型声明 `status=failed` 不会被记为完成。 |
| RES-03 / IR-05 通知 | 低优先级前台通知显示步骤和暂停/终止；确认、追问、接管、暂停及结束走高优先级通道。内容仅含指令摘要与状态，锁屏隐藏指令；不含截图、模型界面摘要、问题或答案。结束通知独立保留，点击加载对应本地结果，支持进程重启后打开。 |
| RES-04/05 评价与播报 | 正面/负面评价和文字可保存、修改，仅存本机；不上传轨迹或截图。可在设置开启系统 TTS 播报最终状态与答案，默认关闭。 |

Android 禁用模型 SDK 的自动重试，防止暂停后重新上传旧截图；PC 的重试配置不变。设备层在实际派发截图、手势、输入和导航前再校验任务状态与控制版本，快速暂停/继续使旧动作失效。等待手势回调不持有控制锁。App 或通知恢复任务前先退到目标页面；浮窗文字回答先收起输入法。

API 故障分类读取状态码与结构化错误代码。429 会进一步区分额度不足与请求限流，依据 [OpenAI 错误码说明](https://developers.openai.com/api/docs/guides/error-codes)；第三方服务的非标准错误可能只能归入请求失败。豆包 API 异常改为抛出 `VLMAPIError`，避免连接失败被误记为 COMPLETE。

## 记录与回放

每次任务的私有 `runs/<task_id>/` 保存截图、`trace.jsonl`、`interactions.jsonl`、`summary.json`。追问及回答进入步骤 notes，App 当前任务时间线可以查看；控制事件记录时间和步骤号，并附到后续步骤的 interactions。暂停期间收到的旧预测保留在交互日志；恢复观察使用带 retry 后缀的新截图，不覆盖旧图。

```shell
python scripts/replay.py runs/<task_id>
```

回放显示问答与暂停/继续、接管开始/结束时间；没有截图就进入接管的任务也能查看交互记录。当前没有新增完整的历史任务管理页。CLI/Web 调试器尚未接入这套追问界面，遇到需要交互的模型动作会安全中止，原因是 `interaction_unavailable`。

## 验证边界

离线测试覆盖两种 OpenAI 协议的真实 SDK + mock HTTP 请求、连接故障、暂停期间保留响应及用量计数、恢复重观察、原生派发门禁、追问超时、问答上下文、确认超时/重复响应、通知隐私、答案截图来源和结果/评价持久化。本次只补关键回归，不为简单文案和重复映射增加用例；完整测试 suite 目标为 5 分钟内。构建结果、实测耗时与测试总数见 [Android 指南](../android/README.md)。

尚无本轮真机验证：设备上的浮窗输入焦点、通知交互/2 秒送达、系统语音识别与播报、实际应用页面和网络抓包仍需安装 APK 验收。查询准确率未实测，模型提供的答案和截图关联也不等于事实核验。自动识别依赖应用暴露的无障碍节点及模型判断；自绘控件和不公开节点的验证页面可能需要用户主动接管。
