# Android 连接测试、任务控制与人机交互

对应 Android 1.3（versionCode 4），覆盖 FR-ACC-05、FR-INT-02/03/04。实现位于 SeeTouch 本体，不依赖网关。

| 需求 | 使用方式与行为 |
|---|---|
| ACC-05 连接测试 | 设置页点击“测试连接”，使用当前填写、尚未保存的配置，向所选协议发送内置示例图及固定问题。成功显示耗时；失败区分网络、鉴权、额度、模型/接口不存在、无法解析，另外区分限流和服务异常。测试不读取手机屏幕，不执行模型动作。修改配置后旧测试结果失效。 |
| INT-02 暂停、继续、终止 | App、进度浮窗和任务通知提供控制按钮。暂停立即关闭新动作入口，已派发的手势可以结束；已发出的请求可等待返回，结果保留但不执行。继续后重新截图和推理。终止后禁止恢复、禁止新动作；正在等待的请求可能到超时才释放后台线程，期间不能启动另一任务。 |
| INT-03 ASK_USER | 模型可输出问题和选项。浮窗支持选项与文字，通知支持快捷回复；App 支持选项、文字及系统语音识别。识别文字经用户确认后提交。5 分钟未回答进入暂停，保留问题；回答写入当前步骤和后续任务上下文。用户主动暂停后提交答案仍保持暂停，需再点继续。 |
| INT-04 TAKE_OVER | 无障碍节点检测密码、验证码、登录表单、生物识别、滑块等页面，模型也可主动请求接管；用户可随时点“我来操作”。接管期间不发起新的截图、模型请求或自动操作。用户完成后点击继续，重新观察页面。只记录接管边界和原因，不记录人工操作过程。 |

Android 禁用模型 SDK 的自动重试，防止暂停后重新上传旧截图；PC 的重试配置不变。设备层在实际派发截图、手势、输入和导航前再校验任务状态与控制版本，快速暂停/继续使旧动作失效。等待手势回调不持有控制锁。App 或通知恢复任务前先退到目标页面；浮窗文字回答先收起输入法。

API 故障分类读取状态码与结构化错误代码。429 会进一步区分额度不足与请求限流，依据 [OpenAI 错误码说明](https://developers.openai.com/api/docs/guides/error-codes)；第三方服务的非标准错误可能只能归入请求失败。豆包 API 异常改为抛出 `VLMAPIError`，避免连接失败被误记为 COMPLETE。

## 记录与回放

每次任务的私有 `runs/<task_id>/` 保存截图、`trace.jsonl`、`interactions.jsonl`、`summary.json`。追问及回答进入步骤 notes，App 当前任务时间线可以查看；控制事件记录时间和步骤号，并附到后续步骤的 interactions。暂停期间收到的旧预测保留在交互日志；恢复观察使用带 retry 后缀的新截图，不覆盖旧图。

```shell
python scripts/replay.py runs/<task_id>
```

回放显示问答与暂停/继续、接管开始/结束时间；没有截图就进入接管的任务也能查看交互记录。当前没有新增完整的历史任务管理页。CLI/Web 调试器尚未接入这套追问界面，遇到需要交互的模型动作会安全中止，原因是 `interaction_unavailable`。

## 验证边界

离线测试覆盖两种 OpenAI 协议的真实 SDK + mock HTTP 请求、五类连接故障、暂停期间保留响应、恢复重观察、连续快速切换 10 次、原生派发门禁、手势等待与暂停响应、追问超时、问答上下文和回放。构建结果与测试总数见 [Android 指南](../android/README.md)。

尚无本轮真机验证：设备上的浮窗输入焦点、通知交互、系统语音服务、实际应用页面和网络抓包仍需安装 APK 验收。自动识别依赖应用暴露的无障碍节点及模型判断；自绘控件和不公开节点的验证页面可能需要用户主动接管。该能力不是所有凭据页面的识别保证。
